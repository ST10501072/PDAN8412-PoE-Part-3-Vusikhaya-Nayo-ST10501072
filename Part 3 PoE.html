Abstract¶

This notebook builds and evaluates two Convolutional Neural Networks (CNNs) on the CIFAR-10 dataset (60,000 images, 32x32, 10 classes) to classify images and to assess whether the same approach could be trusted for facial recognition.

Note: Appendix evidence only. Full narrative in main Word/PDF report. All metrics computed from model outputs - no hard-coded values.

Model 1 (Baseline): 3 conv blocks, no augmentation, no dropout - Test Accuracy 72.22%, overfit (Train 82.62% vs Val 72.66%). Model 2 (Retrained): Augmentation + Dropout 0.5 + BatchNorm + Deeper + CosineDecay - Test Accuracy 67.50%, underfit (Train 65.28% vs Val 66.96%).

2. Feature Selection - ANOVA F-test + Learned Selection¶

Why not backward/forward elimination with p-values like Part 2? Part 2 had 3 tabular predictors. Here we have 3,072 correlated pixel features. A p-value per pixel is unstable, and dropping pixels loses spatial context.

Method used:

  1. ANOVA F-test per pixel (f_classif) on TRAIN only - genuine F + p-value, computed
  2. Ablation reasoning: Full RGB vs Grayscale vs Centre-crop
  3. Learned selection: Conv filters + MaxPooling inside network

Decision: Retain all 3,072 features. See Report Section 2.1.

# Build Model 1 - Baseline, no augmentation, no dropout, no BatchNorm
def build_model_1():
    # Conv 32 learns edges, MaxPool halves size, Conv 64 learns textures, Conv 64 learns parts
    model = keras.Sequential([
        layers.Conv2D(32, (3,3), activation='relu', padding='same', input_shape=(32,32,3)),
        layers.MaxPooling2D((2,2)),
        layers.Conv2D(64, (3,3), activation='relu', padding='same'),
        layers.MaxPooling2D((2,2)),
        layers.Conv2D(64, (3,3), activation='relu', padding='same'),
        layers.Flatten(),  # 8x8x64 = 4096 to 1D vector
        layers.Dense(64, activation='relu'),
        layers.Dense(10, activation='softmax')  # 10 classes, probabilities sum to 1
    ])
    # Adam LR 0.001, Categorical Cross-Entropy for multiclass
    model.compile(optimizer=keras.optimizers.Adam(learning_rate=0.001),
                  loss='categorical_crossentropy',
                  metrics=['accuracy'])
    return model

# Augmentation - applied ONLY to training data via preprocessing layers
# EDA showed blurry, off-centre, background-dominated images, so augmentation
# forces model to learn object, not position/background
data_augmentation = keras.Sequential([
    layers.RandomFlip("horizontal"),
    layers.RandomRotation(0.15),
    layers.RandomZoom(0.15),
    layers.RandomTranslation(0.1, 0.1),
])

def build_model_2():
    inputs = keras.Input(shape=(32,32,3))
    x = data_augmentation(inputs)  # Only during training
    x = layers.Conv2D(32, (3,3), activation='relu', padding='same')(x)
    x = layers.BatchNormalization()(x)  # Stabilises training, Ioffe & Szegedy 2015
    x = layers.MaxPooling2D((2,2))(x)
    x = layers.Conv2D(64, (3,3), activation='relu', padding='same')(x)
    x = layers.BatchNormalization()(x)
    x = layers.MaxPooling2D((2,2))(x)
    x = layers.Conv2D(128, (3,3), activation='relu', padding='same')(x)
    x = layers.BatchNormalization()(x)
    x = layers.Flatten()(x)
    x = layers.Dense(128, activation='relu')(x)
    x = layers.Dropout(0.5)(x)  # Dropout 0.5, Srivastava et al. 2014 - prevents overfitting
    outputs = layers.Dense(10, activation='softmax')(x)
    model = keras.Model(inputs, outputs)
    return model

model2 = build_model_2()
model2.summary()

# CosineDecay schedule - LR decays smoothly from 0.001 over 25 epochs
cosine_decay = keras.optimizers.schedules.CosineDecay(
    initial_learning_rate=0.001, decay_steps=25 * (len(X_train)//128)
)

model2.compile(

6. Limitations - (Part 2 Feedback)¶

What was FIXED:

  • Validation set: YES - 5,000 images, EarlyStopping on val_loss
  • Class weighting: YES - computed balanced weights in Model 2
  • Full feature set: YES - all 3,072 pixels + ANOVA ranking
  • Leakage: NO leakage - audit in Cell 7
  • Hard-coded metrics: NONE - all metrics computed via sklearn / model.evaluate() / f_classif

What was NOT DONE - admitted, not faked:

  • Cross-validation: NOT done. Single stratified hold-out used due to 7-35 min CPU time per run. 5-fold CV would take 3+ hours.
  • Threshold tuning: NOT done for CIFAR-10 (multiclass uses argmax). For binary facial verification, threshold MUST be tuned on validation data to balance False Match Rate vs False Non-Match Rate.

Conclusion: Model 1 (72.22%) is best. Model 2 (67.50%) underfits due to over-regularisation. Model is NOT suitable for facial recognition - see main report Section 7.
